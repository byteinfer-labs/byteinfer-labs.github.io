# Self-hosted research-page fonts

These are the unmodified Latin variable WOFF2 files served by Google Fonts.
The page uses Inter weights 400–800 and JetBrains Mono weights 400–600.
Both fonts are distributed under the SIL Open Font License; their license
and copyright notices are included alongside the files.

Retrieved 2026-10-28 from:

- Inter v20: https://fonts.gstatic.com/s/inter/v20/UcC73FwrK3iLTeHuS_nVMrMxCp50SjIa1ZL7.woff2
- JetBrains Mono v24: https://fonts.gstatic.com/s/jetbrainsmono/v24/tDbv2o-flEEny0FZhsfKu5WU4zr3E_BX0PnT8RD8yKwBNntkaToggR7BYRbKPxDcwg.woff2
- Inter license: https://github.com/google/fonts/blob/main/ofl/inter/OFL.txt
- JetBrains Mono license: https://github.com/google/fonts/blob/main/ofl/jetbrainsmono/OFL.txt

The font URLs in `research/index.html` include a version so future font
updates can use a new filename without stale cached responses.
